## The defect this audit found in its own release candidate

`templates/base/language/python.md` was committed with 146 CRLF pairs and one
`\r\r\n`, violating `base-quality`'s rule that committed line endings MUST be
LF. It was the only such file in the repository, and it landed one commit after
the release rule that a program pins its line ending as well as its encoding.

`.gitattributes` did not stop it because `text=auto` is a heuristic: a lone
carriage return makes git classify the blob as binary and skip the conversion,
filing it `i/-text` rather than `i/crlf`. The check this project ships for
exactly this failure named `i/crlf`, so it printed nothing, passed, and was
reported PASS in the same conformance run that carried the violation — with
smoke 27/27 and CI green.

Found independently by three dimensions. Fixed during the audit rather than
filed, as #1456 / PR #1457: the file normalised (pairs collapsed *and* the stray
CR stripped, in that order) and the check widened to match any known-text path
that is not `i/lf`. Control, in a throwaway repository carrying the exact shape:
the old form finds 0 rows and the new form finds 1, while a plain-CRLF file
normalises to `i/lf` and is correctly ignored, and the two PNGs are not flagged.

Blast radius was contained — `generated/` carried 0 CR bytes throughout, because
`resolve.py` reads in text mode. That same lossy read is why
`resolve.py --check` reported "up to date": it applies it to both sides of its
own comparison.

## Method note

Seven subagents, one per dimension, each with its own context window and no
sight of the others. Each was given its dimension's 2026-09-01 findings and told
to reconcile against them before looking for anything new, per the prior-record
requirement in `360-execution`.

**Convergence is treated as evidence.** Three dimensions reached the committed
CRLF independently, three reached the chain-budget ratchet independently, and
three reached the Cursor output-file contradiction. Where isolated reviewers
converge on a measurement, it is recorded once and cited from each.

**Every headline finding was re-measured by the assembling agent before being
recorded here**, not accepted from the report. That surfaced two corrections:

- The DEPENDS-ON closure gap is **65** files, not the 38 the Value report gave.
  The difference is where the walk starts; the substantive claim — `readme.md`
  and `review.md` missed by 17 of 17 — holds either way, and the larger figure
  is the one recorded.
- The Discovery report's ADR-024 breach is not a breach, for the reason given in
  section 7.

**A control was demanded of every uniform result.** The chain-budget zero was
confirmed by planting a decrease; the CRLF check by building a throwaway
repository carrying the exact defect shape; the PyYAML claim by shadowing the
module and restoring it; the PLAYBOOK claim by running the flag it denies and an
unknown flag beside it. One control changed an answer: the first widened CRLF
pattern split on whitespace and matched nothing, because only the path in
`git ls-files --eol` is tab-delimited. It was caught because the control was run
in the direction that must fail, not only the direction that must pass.

**What is not here.** Roughly forty Low and Nit findings across the seven
reports are recorded in the Issues section by category rather than filed
individually, and the per-dimension tables above carry the material rows rather
than every row. The full reports were longer than this record; nothing rated
Medium or above was dropped.

**Grades fell in six of seven dimensions and none rose.** That is worth reading
correctly. Every prior High was closed, and both prior bottlenecks — SYS-11's
blind spot and the model-limitations table — are genuinely gone, verified with
injected controls rather than taken on trust. The reviewers, not spending their
budget re-deriving last time's findings, looked one layer down and found the
layer below in worse shape than the one above it. The pattern that recurs at
every level is a mechanism whose aperture is narrower than its subject: a check
matching `i/crlf` over a file filed `i/-text`, a ceiling that records what it
claims to refuse, a redundancy audit scanning 46% of roots, a README instruction
that cannot reach the tier it depends on.
