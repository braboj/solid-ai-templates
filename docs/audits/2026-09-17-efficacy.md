# Efficacy benchmark — 2026-09-17

Does a generated context file improve the result? The question, the verdict rule and the
metric directions were fixed before any trial ran, in
`docs/design/efficacy-benchmark.md`.

**Every interval below is descriptive.** At K = 3 no arrangement of paired differences
reaches conventional significance, which the design states and this report repeats
rather than footnotes.

| | Templates' file, 406 lines | Hand-written file, 39 lines |

## Summary

| Comparison | Score, 1-10 | Wins | Fails |
|---|---|---|---|
| Templates (B) vs no context file (A) | 4.8 | 8 | 11 |
| Hand-written file (C) vs no context file (A) | 8.2 | 16 | 4 |
| Templates (B) vs hand-written file (C) | 3.0 | 4 | 14 |

The score is 1 + 9 × wins ÷ (wins + fails). A win or a fail is a metric whose interval
separated the pair in its declared direction, each metric counting once; one showing no
improvement counts neither way. The verdict vector at the end names them. The score
digests it and decides nothing.

Caveats: 9 trials, 9 judged; escalation to K = 5 not owed, so K stays 3; withdrawn:
Change task, acceptance pass rate; lost and re-run: C2 (change task), completed; reached
past their workspace: C3 and B3 (change task); the judge is checked only by its evidence
lines.
